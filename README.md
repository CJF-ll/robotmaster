## 第二次作业：理论理解题

### 1. 小陀螺为什么会给传统自瞄算法带来挑战？

小陀螺是机器人底盘快速旋转的状态。此时，装甲板并不是沿着一条近似直线移动，而是绕机器人中心周期性运动。一块装甲板可能很快转到背面、离开视野，另一块又进入视野。检测结果看起来会突然跳到另一个位置。

如果算法把前后两帧检测到的装甲板当成同一个目标，并按匀速直线运动预测，就可能算错速度和提前量，甚至跟错装甲板。要应对这种情况，需要先稳定地跟踪机器人中心和旋转状态，再判断当前看到的是哪块装甲板，预测开火时可见装甲板的位置。

### 2. 图像分类和目标检测的核心区别是什么？

图像分类回答“这张图主要是什么类别”，通常给整张图一个类别标签。例如，输入一张机器人照片，输出“机器人”。

目标检测除了判断类别，还要回答“目标在哪里”。它通常为图中每个目标给出类别、位置框和置信度。因此，一张图中有多个机器人时，检测算法可以分别标出它们；分类算法只给整张图分类，不能直接指出每台机器人的位置。

### 3. 什么是相机畸变？不标定为什么会影响测距？

理想的针孔相机模型假设空间中的点会按固定的几何关系投影到图像上。实际镜头会使成像位置偏离这个模型，这种偏差叫畸变。常见的径向畸变会让图像边缘向内或向外弯曲；镜头与传感器安装不完全对齐，还可能产生切向畸变。

测距和位姿估计要把图像中的二维角点还原为空间中的三维位置。如果角点像素位置因畸变发生偏移，后续的 `solvePnP` 就会根据错误的点位计算，得到有偏差的距离和姿态。相机标定会求出内参矩阵和畸变系数；使用这些参数修正图像或角点后，测距结果通常会更可靠。

### 4. `solvePnP` 需要哪些输入？角点误差为什么会造成三维位置抖动？

`solvePnP` 主要需要四组信息：目标上已知的三维点坐标、图像中对应的二维点坐标、相机内参矩阵和畸变系数。三维点与二维点必须**逐一对应，顺序一致**。函数解算后得到目标相对相机的旋转向量和平移向量。

实际检测时，同一个角点可能因光照、模糊或检测误差在相邻帧偏移几个像素。`solvePnP` 每帧都会重新利用这些角点求解；二维位置一变，算出的三维位置也会跟着变。在目标较远或图像中目标较小时，几个像素的误差可能造成更明显的距离变化，于是静止目标的计算结果也会抖动。

### 5. 为什么不能只用相邻两帧的位置差算速度？卡尔曼滤波有什么作用？

用两帧位置计算速度的公式是 `v = (x₂ - x₁) / Δt`。但视觉测得的位置含有像素噪声、检测框和角点抖动，以及 PnP 解算误差。当两帧间隔很短时，位置上的小误差会被除以很小的 `Δt`，变成很大的速度误差；丢帧或帧间隔变化也会让结果不稳定。

卡尔曼滤波可以理解为反复进行“预测、修正”：先根据上一时刻的位置和速度预测下一时刻的状态，再结合相机的新观测修正预测。它会考虑预测和观测各自的不确定性，而不是完全相信其中一方。这样可以减小位置与速度的抖动，并在短时间丢失目标时继续预测。自瞄还需要结合子弹飞行时间，利用估计出的运动状态预测命中时目标的位置。
