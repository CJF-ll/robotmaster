# 第二次作业：理论理解题

## 1. 小陀螺为什么会给传统的自瞄算法带来巨大挑战？

在 RoboMaster 比赛中，“小陀螺”通常是指机器人底盘快速旋转，使机器人身上的装甲板不断围绕机器人中心运动，传统自瞄算法通常假设目标在短时间内的运动比较连续，比如根据上一时刻的位置和速度预测下一时刻的位置。但在小陀螺状态下，装甲板进行的是快速的周期性旋转运动，而不是普通的直线运动，因此会给传统自瞄带来很大困难

主要有以下几个原因：
1. 装甲板在图像中的位置变化很快
2. 一块装甲板可能会转到机器人背面，从视野中消失
3. 另一块装甲板又会重新进入相机视野
4. 不同装甲板切换时，检测到的位置可能突然发生跳变
5. 普通的匀速直线运动模型很难准确预测装甲板未来的位置

因此，小陀螺会增加目标跟踪、速度估计和位置预测的难度，容易出现跟错目标、预测位置错误以及瞄准点跳动等问题

## 2. 图像分类（Image Classification）和目标检测（Object Detection）的核心区别是什么？

图像分类和目标检测都是计算机视觉中的基本任务，但是它们解决的问题不同

### 图像分类

图像分类主要解决的是：
> 这张图片中的物体是什么

目标检测主要解决的是：
> 这张图片中的物体是什么，物体在哪里

## 3. 什么是相机畸变？为什么不标定会影响测距精度？

理想情况下，相机可以近似看成一个针孔相机，现实世界中的直线经过成像以后仍然应该是直线，但是实际相机都有镜头，由于镜头制造工艺和安装误差等原因，实际成像会偏离理想的针孔模型，这种现象就叫做相机畸变。
常见的畸变主要有两种：

1）径向畸变
径向畸变主要由镜头本身造成
桶形畸变
枕形畸变
通常图像越靠近边缘，畸变越明显。

2）切向畸变
如果镜头和相机传感器安装时没有完全平行，也可能导致图像发生一定的偏移，这种情况叫做切向畸变
在视觉测距中，需要利用目标在图像中的二维像素坐标来计算目标在真实世界中的三维位置，如果存在畸变，装甲板角点的真实位置和相机拍摄到的位置就会产生偏差，虽然只相差几个像素，但后续 PnP 会根据这些二维角点计算目标的三维位置，因此会造成距离和姿态的误差

相机标定可以得到：

相机焦距
相机光心
相机内参
镜头畸变参数

利用这些参数可以对相机畸变进行修正，从而提高测距和位姿估计的准确性。

## 4. solvePnP 解算时需要哪些输入？二维角点误差为什么会导致三维位置抖动？

solvePnP 主要需要以下输入

1. 物体的三维坐标

2. 图像中的二维角点

3. 相机内参矩阵

主要包括：

x 方向焦距 fx

y 方向焦距 fy

光心横坐标 cx

光心纵坐标 cy

4. 相机畸变参数

这些参数通常通过相机标定获得。

为什么二维角点误差会导致三维位置抖动？

实际检测中，装甲板角点的位置不可能每一帧都完全相同

例如同一个角点可能被检测为：

第一帧：(400, 200)
第二帧：(402, 199)
第三帧：(399, 202)

虽然这些误差只有几个像素，但是 solvePnP 每一帧都会重新根据这些二维角点计算目标的三维位置，因此，即使目标本身没有运动，计算出来的三维位置也可能发生变化

例如目标真实距离一直约为 5 米，但计算结果可能是：

第一帧：4.98 m
第二帧：5.06 m
第三帧：4.93 m
第四帧：5.02 m

出现了三维抖动

## 5. 为什么不能只用相邻两帧的位置差计算目标速度？卡尔曼滤波在这个场景下有什么作用？

最简单的速度计算方式是：
速度 = 位置变化量 / 时间变化量
也就是：
v = (x2 - x1) / Δt
但是视觉系统测量得到的位置本身就存在误差
例如目标真实的位置变化可能是：
100 → 108
但由于检测误差，视觉系统可能测成：
100 → 110
假设两帧之间的时间只有：0.01 s
那么 2 个单位的位置误差就会变成：
2 / 0.01 = 200
因此，位置上的小误差在计算速度时会被明显放大。
视觉系统中常见的误差包括：

1. 像素噪声
相机受到传感器、光照和电子噪声等影响，即使目标没有运动，图像中的像素值和边缘位置也可能发生轻微变化。
2. PnP 抖动
二维角点存在微小误差时，通过 PnP 计算得到的三维位置也会发生变化，从而使目标的空间坐标出现轻微抖动。
3. 检测框抖动
即使目标没有运动，目标检测算法每一帧输出的矩形框位置和大小也可能发生少量变化。
4. 偶尔丢帧
由于目标遮挡、运动模糊、光照变化或者检测置信度过低，某一帧可能无法成功检测到目标。
5. 角点误差
装甲板角点的位置可能因为图像模糊、目标倾斜或者检测算法误差而出现几个像素的偏差。
因此，如果只使用相邻两帧的位置差计算速度，得到的速度会很不稳定。

卡尔曼滤波的作用
卡尔曼滤波可以简单理解为：
预测 + 修正
首先，它会根据目标上一时刻的位置和速度，预测目标下一时刻应该出现在哪里。
例如：
上一时刻位置：10 m
速度：2 m/s
经过时间：0.1 s
那么预测下一时刻的位置大约是：
10.2 m
但是此时相机可能实际测量得到：
10.6 m
卡尔曼滤波既不会完全相信预测值，也不会完全相信当前测量值，而是把两者结合起来，得到一个更加稳定、更加合理的估计结果。

在 RoboMaster 自瞄系统中，卡尔曼滤波主要有以下作用：

1.减少目标位置抖动
2.得到更加稳定的速度估计
3.在短时间丢失目标时继续预测
4.预测目标未来的位置

由于子弹从发射到命中目标需要一定时间，因此自瞄系统不能只瞄准目标当前的位置，而应该根据目标的运动状态预测目标未来的位置，从而实现提前瞄准。
