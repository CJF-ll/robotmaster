# 自瞄作业二：运动解算

## 实验完成内容

我使用 C++17 和 OpenCV 完成了前哨站三块装甲板的灯带检测、连续相对编号、运动状态估计、短时位置预测和视频叠加。程序在 Ubuntu 虚拟机中完成编译、测试和整段视频处理。

画面中的标记含义如下：

- 绿色实线四边形：当前帧中最高置信度的真实双灯带检测框。
- 绿色虚线四边形：当前时刻另外两个相对编号槽位的模型位置。
- 红色虚线四边形：当前可见装甲板在未来 3 帧的位置；与绿色框重叠时改为较细的半透明虚线，但不会隐藏。
- `A1`、`A2`、`A3`：以首个可见装甲板为 `A1` 建立的连续相对跟踪编号。
- `USED`、`GATED`：当前绿色实线候选是否参与相位和角速度状态更新。
- CSV 的 `measurement_used` 表示本帧任一候选是否参与状态更新，`candidate_measurement_used` 专门对应画面中的最高置信度候选。

## 算法实现

### 1. 灯带提取与配对

我先使用归一化 ROI 限定检测区域，再结合红通道亮度、`R-G` 和 `R-B` 通道差提取红橙色区域。轮廓经过面积、长度、宽高比和倾角筛选后形成灯带候选；两根灯带再按照中心间距、高度差、长度比和倾角差完成配对。

检测器按照配对得分从高到低排列候选。最高置信度候选负责绿色当前框和图像位置预测；相位关联器可以从全部候选中选择最符合连续运动状态的观测用于滤波。两条链路分开后，状态门控不会替换或拉偏真实灯带框。

### 2. 灯带外缘四边形

我从每根灯带的旋转矩形中提取长轴方向、宽度和四个顶点，再使用左右灯带的外侧上下端点生成固定顺序 `{TL, TR, BR, BL}`。端部与侧面留量同时使用比例值和像素下限。

生成后检查四边形的凸性、面积、对边比例以及对两根灯带的包含关系。普通连接不能完整覆盖灯带时，程序使用两条灯带外侧边与上下支撑线重新求交。退化配对和单灯带不会生成完整装甲板框，因此透视情况下可以得到随灯带形状变化的梯形，而不是固定旋转矩形。

### 3. 固定相机二维投影模型

我使用二维仿射投影描述三块装甲板中心在画面中的运动：

```text
p_i(theta) = center + axis_cos * cos(theta + i*120°)
                      + axis_sin * sin(theta + i*120°)
```

程序先扫描整段视频，从真实检测中心拟合圆周在图像中的椭圆投影，再通过帧间差分得到运动区间，并用视频自相关估计重复周期。角速度和旋转方向均来自当前视频观测，没有写死轨迹或角速度。

本次视频尺寸为 668 × 688，没有与该相机、镜头和裁剪方式匹配的标定板数据，因此 `camera_enabled` 为 `0`。相机内参、畸变系数、装甲板尺寸、旋转半径和俯角均保留在 YAML 中；未实测的三维参数记为 `0`，不参与本次 `affine` 解算。

### 4. 相位四边形模型与连续相对编号

我将有效观测按旋转相位分为 36 个循环区间，对每个区间的中心残差和四个角点偏移取鲁棒中位数。缺失区间先进行循环插值，再进行循环平滑，所以模型框会随相位产生透视收窄和倾斜。

相位滤波使用内部的 `measurement_slot_index`；当前真实框使用独立的 `detected_slot_index`。发生经过图像连续性门控确认的周期性交接时，相对编号按本视频的旋转方向原子更新。CSV 另外记录 `candidate_association_slot_index` 和 `future_slot_index`，避免把相位槽位、显示编号和未来编号混为同一个字段。

### 5. 状态更新与运动判定

我用统一的相位状态维护角位置、角速度和角加速度。观测通过关联门限后才修正状态；短时漏检期间继续使用模型输出，超过 `max_prediction_frames` 后停止绘制模型框，运动模式再经过 `mode_hold_frames` 的状态保持进入 `LOST`。

运动状态包括 `STOPPED`、`UNIFORM`、`ACCELERATING`、`DECELERATING`、`REVERSING` 和 `LOST`，旋转方向输出为 `CW`、`CCW` 或 `STOP`。

### 6. 五帧鲁棒图像速度

我使用最近 5 个通过独立图像连续性门控的检测中心估计当前可见装甲板的图像速度。对时间窗中全部点对分别计算 `x(t)`、`y(t)` 斜率，再取 Theil–Sen 中位数；速度拟合使用视频时间戳。

连续运动时的未来中心为：

```text
future_center = current_center + robust_velocity * prediction_lead_s
```

预测四边形沿用当前真实灯带框的四个角点并整体平移。连续步长、周期性交接范围、方向一致性和历史超时均由 YAML 控制。候选被图像门控拒绝时不会污染速度历史；短时漏检使用最后一次可信观测和已有速度续推。

### 7. 数据驱动的未来换板预测

本程序采用单视频离线处理流程：先扫描整段输入视频，从满足连续性门控的大跳变中提取每个相对编号的退出框、进入框和图像跳变方向，再从头重放并输出结果。每个编号的模板由多次事件取鲁棒中位数，样本数不足时不启用该先验。该先验用于本视频重放，不把同视频指标当作跨视频泛化结果。

程序为未来 3 帧是否换板计算三项独立证据：

1. 当前鲁棒速度在预测时域内是否越过退出位置。
2. 轨迹分数 `progress - weight × age` 是否到达从视频学习的门限。
3. 当前装甲板从上次交接开始已经连续跟踪的帧数是否到达学习门限。

`progress` 是检测中心在自动学习的交接方向上的投影，`age` 是当前相对编号持续跟踪的帧数。每个编号分别搜索 `weight` 和分数门限；三项证据达到 YAML 中设置的票数后，红色未来框切换到下一块装甲板的进入模板并继续外推。第一次交接尚无在线速度时，程序只在整段视频标定出的首个交接窗口内使用“进度 + 帧龄”两票完成冷启动。

### 8. 连续未来状态与重叠显示

我把图像外推得到的未来框作为原始测量，再使用持续的 alpha-beta 状态进行逐帧预测和校正。状态保存未来中心、中心速度以及四个角点相对中心的形状；中心增益、速度增益、形状增益、重置距离、最大时间间隔和速度上限全部由 YAML 配置。本视频采用的中心增益为 0.55，速度增益为 0.08。

同一编号内，状态先按上一帧速度预测，再使用当前原始未来位置修正，因此检测噪声不会直接变成红框的逐帧跳动。未来编号发生变化时，中心、速度和四角状态直接重置到下一块真实装甲板，不在两块装甲板之间生成不存在的过渡框。绿色框始终使用当前检测结果，不参与这一级平滑。

渲染层不再通过距离或 IoU 隐藏有效红框。红绿框重叠时，红框切换为细的半透明虚线并保留中心标记；进入和退出重叠状态使用两组阈值形成迟滞，短时漏检继续保持上一种样式，避免阈值附近或检测缺帧时反复切换。超过预测时限后，求解器将未来框置为无效，渲染层才停止绘制。

## 配置文件

实验参数集中保存在 `config/video.yaml`：

- `solver_mode`：二维解算模式，本次为 `affine`。
- `camera_*`、`fx/fy/cx/cy`、`k1/k2/p1/p2/k3`：去畸变开关、参考分辨率、相机内参和畸变系数。
- `armor_width_m`、`armor_height_m`、`rotation_radius_m`、`outpost_pitch_deg`：实体尺寸和安装姿态。
- `roi_*`、`red_*`、`min_light_*`、`max_light_*`：检测区域、颜色与单灯带筛选参数。
- `min_pair_*`、`max_pair_*`：双灯带配对参数。
- `quad_*`：灯带外缘四边形的留量与合法性参数。
- `geometry_*`、`ellipse_*`、`shape_*`、`model_offset_*`：二维几何与相位四边形学习参数。
- `phase_*`、`speed_*`、`acceleration_*`、`max_observation_distance_px`：状态关联与滤波参数。
- `prediction_*`：预测时域、漏检显示时限、重叠样式迟滞阈值和半透明系数；秒数大于 0 时按输入 FPS 量化到最近的完整帧，并同步更新帧数与秒数。
- `future_target_filter_*`：红色未来框的持续中心/速度/形状状态、校正增益和重置条件。
- `image_prediction_window_frames`、`image_prediction_min_samples`、`image_prediction_velocity_gain`：Theil–Sen 图像速度窗口。
- `image_prediction_history_timeout_s`、`image_prediction_max_step_px`、`image_prediction_jump_*`：可信历史、连续步长和周期性交接门控。
- `image_prediction_handover_*`：交接先验开关、投票数、每槽最少事件数、帧龄搜索范围，以及线性分数中帧龄权重的搜索上限和步长。
- `stationary_*`、`uniform_*`、`mode_hold_frames`、`motion_*`、`period_search_*`：运动模式、运动区间和重复周期估计参数。

## 输出结果

程序生成：

1. MP4：原视频、三槽位当前框、未来 3 帧目标框、相对编号、旋转方向、角速度、运动模式和预测器状态。
2. CSV：逐帧保存最高置信度候选及其采用状态、全候选相位测量状态、图像连续性门控、三项交接投票、相对显示编号、相位测量槽位、候选关联槽位、未来编号、原始与滤波后的未来中心、滤波创新量和速度、重叠渲染状态、相位、角速度、重投影误差和所有框中心。

CSV 内部槽位字段均为从 `0` 开始的 `*_slot_index`；画面中的 `A1/A2/A3` 和 `future_target_id` 从 `1` 开始。`current_detection` 表示真实检测框，`current_model` 表示相位模型框。

## 验证结果

我使用 `tests/test_main.cpp` 验证了灯带四边形、灯带包含检查、单灯带拒绝、极窄与退化配对、相位循环插值、连续相对编号、状态门控、五帧鲁棒速度、未来框连续滤波、换板原子重置、重叠显示迟滞、离群候选续推、周期性交接、首轮冷启动和 YAML 参数校验，全部测试通过。

以下结果来自“整段视频离线标定后，从第 0 帧重新重放”的 925 帧回归，不是独立视频或留出片段测试：

- 923 帧检测到有效双灯带候选，709 帧观测参与相位状态更新。
- 离线门控在重放中标记了 38 次周期性交接。
- 923 帧使用图像运动预测，其中 2 帧为短时漏检续推。
- 未来框滤波在 925 帧均有效，首次建立状态和 38 次换板共触发 39 次原子重置。
- 红色未来框在 925/925 帧均被绘制，全片只有 1 个连续显示区间；203 帧采用重叠样式，迟滞状态仅切换 4 次。
- 运动区间方向保持为 `CCW`，有效运动帧角速度中位数为 63.63°/s。
- 将第 `k` 帧的 3 帧预测与第 `k+3` 帧检测对齐，共得到 920 组样本：滤波后中心误差中位数 5.38 px，P90 13.12 px，P95 17.73 px，P99 103.78 px，最大值 159.68 px。
- 未来相对编号匹配的 910 组样本中，滤波后中心误差中位数 5.35 px，P90 12.80 px，P95 15.68 px，P99 26.02 px，最大值 39.51 px。
- 未来相对编号匹配率为 910/920，即 98.91%。
- 同一编号内的单帧位移 P95 从原始预测的 15.82 px 降为 12.89 px，最大值从 44.69 px 降为 31.31 px。
- 同一编号内的二阶位置变化 P95 从 17.40 px 降为 8.09 px，最大值从 49.50 px 降为 23.43 px。
- 交接边界处超过 80 px 的大误差由优化前的 35 帧降为 10 帧。
