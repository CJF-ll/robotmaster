# 自瞄作业二：运动解算

## 实验完成内容

我使用 C++17 和 OpenCV 完成了前哨站三块装甲板的检测、固定编号、运动解算与视频叠加。程序从原视频中提取红橙色灯带，根据两根灯带的真实外缘生成装甲板四边形，并在连续帧中输出旋转方向、角速度、角加速度和运动模式。

我将画面中的信息分为当前状态和预测状态：

- 绿色实线框表示当前帧检测到的真实灯带四边形。
- 绿色虚线框表示当前时刻另外两个固定编号槽位的模型位置。
- 红色虚线框表示当前可见装甲板在未来 3 帧的位置。
- 黄色箭头表示当前检测中心到预测中心的位移。
- `A1`、`A2`、`A3` 是三个连续且固定的装甲板编号。

检测候选未通过状态滤波门限时，绿色实线框仍使用本帧真实检测结果；`USED` 和 `GATED` 只表示该观测是否参与相位和速度更新。红色预测框与绿色当前框重合度过高时会隐藏，避免两个框叠在一起。

## 算法实现

### 1. 灯带提取与配对

我先限定归一化 ROI，再结合红通道亮度、`R-G` 和 `R-B` 通道差提取红橙色区域。轮廓经过面积、长度、宽高比和倾角筛选后形成灯带候选。我按照两根灯带的中心间距、中心高度差、长度比和倾角差完成配对。

### 2. 灯带外缘四边形

我从每根灯带的旋转矩形中提取从上到下的长轴、宽度和四个顶点，再使用左右灯带的外侧上下端点生成固定顺序的 `{TL, TR, BR, BL}`。端部和侧面留量分别由比例值与像素下限共同确定。

生成后，我检查四边形的凸性、面积、对边比例以及对两根灯带的包含关系。普通连接不能完整覆盖灯带时，我使用两条灯带外侧边与上下支撑线重新求交。退化配对和单灯带不会生成完整装甲板框。

### 3. 固定相机二维投影模型

我采用二维仿射投影描述三块装甲板的旋转中心：

```text
p_i(theta) = center + axis_cos * cos(theta + i*120°)
                      + axis_sin * sin(theta + i*120°)
```

该表达式对应圆周在固定相机画面中的椭圆投影。程序先扫描整段视频，从有效观测拟合投影中心和两条椭圆轴，再根据图像帧间差分定位运动区间，并通过自相关估计三块装甲板的重复周期。角速度和旋转方向均由视频观测计算，不使用写死的运动轨迹。

本次输入视频为 668 × 688，而配置中已有的标定参数来自另一段 1920 × 1080 视频，因此我在本次实验中将 `camera_enabled` 设为 `0`，直接在原始二维画面中完成解算。相机内参、五个畸变参数、装甲板宽高和旋转半径均保存在 YAML 中；其中实体尺寸不参与本次 `affine` 解算。

### 4. 相位四边形模型与固定编号

我把有效观测按照旋转相位划分为 36 个循环区间，对每个区间的中心残差和四个角点相对中心的偏移取鲁棒中位数。缺失区间通过循环插值补齐，随后进行循环平滑。这样得到的模型四边形会随相位产生透视收窄和倾斜，而不是使用固定尺寸的旋转矩形。

我将每个观测中心映射到椭圆相位，并在相差 120° 的三个槽位中选择与连续运动状态最一致的槽位。三个槽位始终对应 `A1`、`A2`、`A3`，从而保持编号连续。

### 5. 状态更新与运动判定

我使用统一的相位状态维护角位置、角速度和角加速度。观测通过关联门限后用于修正状态；短时漏检期间由模型继续输出当前位置，超过 `max_prediction_frames` 后状态进入 `LOST`。

运动状态由角速度、角加速度、方向变化和保持帧数组合判断，输出包括 `STOPPED`、`UNIFORM`、`ACCELERATING`、`DECELERATING`、`REVERSING` 和 `LOST`。旋转方向输出为 `CW`、`CCW` 或 `STOP`。

### 6. 五帧鲁棒位置预测

我使用最近 5 个有效检测中心估计当前可见装甲板的图像速度。对于 `x(t)` 和 `y(t)`，我计算时间窗内所有点对的斜率，再分别取 Theil–Sen 中位数。时间变量直接使用视频时间戳，因此变帧率不会被当成速度变化。

我将预测时间设为 3 帧；输入为 30 fps 时，对应 0.10 s。预测中心按下式计算：

```text
future_center = current_center + robust_velocity * prediction_lead_s
```

预测四边形沿用当前真实灯带框的四个角点，并整体平移到预测中心。检测中心发生装甲板周期性交接时，我清空当前短时拟合窗口，并单独记录退出位置和进入位置，避免把画面跳转误认为瞬时高速。有效连续样本不足或短时漏检时，我使用相位、角速度和受限角加速度完成预测。

## 配置文件

我将实验参数集中写入 `config/video.yaml`：

- `solver_mode`：本次实验使用的二维解算模式，值为 `affine`。
- `camera_enabled`、`camera_reference_width/height`、`fx/fy/cx/cy`、`k1/k2/p1/p2/k3`：图像去畸变和相机标定参数。
- `armor_width_m`、`armor_height_m`、`rotation_radius_m`：装甲板和旋转机构的实体尺寸记录。
- `roi_*`：检测区域的归一化边界。
- `red_*`、`min_light_*`、`max_light_*`：红橙灯带的颜色和几何筛选阈值。
- `min_pair_*`、`max_pair_*`：双灯带配对阈值。
- `quad_*`：灯带外缘四边形的留量和有效性阈值。
- `geometry_*`、`ellipse_*`：椭圆投影几何的离线标定参数。
- `shape_*`、`model_offset_*`：相位四边形学习、循环平滑和模型偏移参数。
- `phase_*`、`speed_*`、`acceleration_*`、`max_observation_distance_px`：关联与运动状态滤波参数。
- `prediction_lead_frames`、`prediction_lead_s`：预测提前帧数和秒数。本次配置为 3 帧、自动按帧率换算秒数。
- `prediction_*`：角加速度限制、漏检显示时限和重叠隐藏阈值。
- `image_prediction_*`：五帧鲁棒拟合、连续步长和周期性交接参数。
- `stationary_*`、`uniform_*`、`mode_hold_frames`：运动模式判定参数。
- `motion_*`、`period_search_*`：运动区间与重复周期估计参数。

## 输出结果

程序输出两类文件：

1. MP4 视频：保留原始画面，并叠加三槽位当前框、未来预测框、固定编号、方向、角速度、运动模式、预测器类型和漏检帧数。
2. CSV 数据：逐帧记录候选状态、候选槽位、观测是否采用、当前相位、未来相位、预测提前量、角速度、角加速度、方向、运动模式、重投影误差、漏检帧数、未来目标中心和三个当前槽位中心。

CSV 中的 `current_detection` 表示当前真实检测，`current_model` 表示当前相位模型补全；`image_motion_prediction_used=1` 表示该帧的红色目标由五帧图像速度模型生成，否则由相位模型生成。

## 验证结果

我使用 `tests/test_main.cpp` 验证了灯带四边形构造、单灯带拒绝、极窄和退化配对、相位循环插值、固定编号、观测门限、漏检状态以及五帧鲁棒速度预测，`ctest` 全部通过。

我对 925 帧完整视频进行了回归处理，得到以下结果：

- 923 帧检测到有效灯带配对。
- 709 帧观测通过状态更新门限。
- 925 帧均生成有效短期目标，其中 921 帧使用五帧图像速度预测，其余帧使用相位模型。
- 运动区间的旋转方向均判定为 `CCW`，有效运动帧角速度中位数为 63.63°/s。
- 我将第 `k` 帧的 3 帧预测与第 `k+3` 帧检测对齐，共得到 916 组可评估样本；预测中心误差中位数为 4.71 px，P90 为 15.17 px。
- 其中 801 组连续轨迹样本的预测误差中位数为 4.10 px，P90 为 11.07 px；在相同样本上直接使用当前中心作为未来位置时，误差中位数为 20.78 px。
