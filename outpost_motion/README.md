# 自瞄作业二：运动解算

使用 C++17、OpenCV 和 YAML 实现视频输入、灯带检测、装甲板关联、运动估计及四边形叠加。开发、构建和回归运行位于虚拟机；本次输入不初始化相机、云台控制或弹道模块。

参考 [TongjiSuperPower/sp_vision_25](https://github.com/TongjiSuperPower/sp_vision_25) 的检测、实测角点、位姿解算和目标状态分层。对照版本为 `bd9f5e798fa3c6dd3b483ae6627796afb41c608d`。本工程没有采用该仓库的固定角速度吸附值，也没有将其相机标定和前哨站尺寸当成本视频参数。

## 当前运行模式

| 模式 | 实现 | 使用边界 |
|---|---|---|
| `image_2d` | 多帧卡尔曼位置/速度估计、局部轨迹、在线三槽位身份假设 | 默认用于本视频；不输出可信物理角速度或三维旋转方向 |
| `calibrated_3d` | 实测灯带端点 → IPPE 位姿 → 三板共同中心/相位 → 短时预测和投影 | 已接入主程序并通过合成测试；必须提供真实 K/D、轴方向和尺寸，尚未在本视频上完成实物验证 |

本视频的相机内参、畸变和实体标定尚未取得，因此正式配置中的未知量保持 `null`，默认使用二维模式。三维模板缺参数时明确报错，不使用示例标定，也不自动退回二维后声称三维预测成功。

两种模式都只消费当前及历史观测；没有整段视频轨迹预学习、相位查表或固定角速度。固定的三板 120° 相对关系是三维目标结构假设，不是预设随时间运动的轨迹。

## 检测与观测几何

传统检测提取灯带轮廓、长轴、宽度和端点，再进行灯带配对。四点固定为 TL、TR、BR、BL。显示外包围框与参与几何解算的灯带中心线端点分开保存，外扩参数不会改变位姿测量。

配对检查凸性、面积、长宽关系、灯带包含和候选归属。单灯带、截断轮廓、交叉/退化配对不会冒充完整观测。观测框可随两根灯带的真实倾角和长度形成梯形。

`detector.endpoint_refinement` 可沿实测长轴的三条灰度剖面寻找半对比度端点；成功时使用有像素支持的端点，失败时保留原二值轮廓并标记 `uncertain`，不会外推未见端点。图像/ROI 边界支持不足仍拒绝。`tracking.common_endpoint_guard` 对成熟轨迹中两灯带同时缩短、而间距未同步缩小的情况记录疑似截短并阻止更新和重复新生。单帧规则短灯带无法证明发生遮挡。这两个选项均默认关闭。

三维估计入口也独立检查 `BoundaryUnsupported`：任意一根灯带缺少边界支持时，不进行PnP、不初始化目标、不更新已有运动历史；已有目标仅按原漏检规则短时预测。传统与网络辅助的实测配对遵循相同检查。`Uncertain` 仅表示可选灰度精化未成功，不等同于边界缺失，仍可使用有效二值实测轮廓。

`neural_supported` 后端先获得网络候选和分类，再与实测灯带对应。新增局部重提取流程：合格网络候选没有全局灯带支持时，在原始像素 ROI 内以独立亮度阈值找灯带。最终仍需要实测双灯带、唯一端点匹配及全局灯带独占；网络四点本身不会直接替代实测角点。候选分类不合格时不进入匹配竞争。

## 运动估计

二维模式使用多帧状态和协方差估计速度，不用最近两帧直接相减。位置与速度滤波、预测有效性、显示权限分别处理：

- 绿色：当前接受的观测；橙色：满足可见灯带支持的短时跟踪框；红色：允许显示的未来框。
- 内部 coast 可以继续数值推算，但不等于画面必须显示完整框；默认无接受观测时不绘制红色未来框。
- 关联歧义会阻止可信预测；空帧不能清除歧义，连续有效观测恢复确认。
- 局部 ID 和三槽位身份假设分开。二维 A1/A2/A3 不是有外部真值保证的永久实体身份，访问顺序也不等于物理 CW/CCW。

二维新生轨迹在等待连续观测确认时，独立显示当帧已接受的真实双灯带绿色框，并标注 `T{id} tentative obs`。暂定观测不进入三槽位身份解算，不产生未来框；缺测、拒绝或歧义候选不会沿用这个绿色框。确认后由原跟踪输出接管，不重复绘制。该显示通道不改变滤波、关联或确认门限。

原视频配置启用 `tracking.center_forecast`：使用最近 9 次连续、已确认的实测中心，以实际视频时间戳拟合二维速度，将“当前实测中心 + 提前量 × 拟合速度”与原滤波预测各取 0.5 融合。最短时间跨度为 0.20 秒，最大相邻间隔为 0.10 秒；窗口、时间门限、融合比例和开关均在 YAML 中配置。其他配置未声明该功能时保持关闭。历史不足、缺测或身份歧义时不使用拟合预测，缺测会清空拟合窗口，恢复后重新积累；相关配置热更新会重置模型。

该模型只使用过去和当前接受观测，不读取未来帧、整段视频轨迹或预设角速度。关联与滤波仍由原跟踪器负责，实测绿框保持原始角点；红框按融合中心整体平移，不独立外推角点。未来协方差考虑末次测量与拟合速度的相关性，以及两个预测的相关性和分歧，保留原协方差下限，不以低估不确定度放宽显示门限。较长窗口不能准确预知突然启停，平移四边形也不等同于预测透视形变。

新增测量质量权重按灯带轮廓拟合残差分别放大 X/Y 测量方差，并在关联、创新检查、滤波更新和新生协方差中使用同一套值。它是有上限的启发式权重，不是经真值标定的概率模型，默认关闭。

新增干净漏检快速恢复仅适用于已成熟轨迹：缺测期间必须完全没有候选，间隔受限，重关联唯一、创新低，并取得连续恢复观测。竞争候选、拒绝候选、低分辨率或质量降权观测不走快速路径；恢复中断则重新确认。该选项不改变位置/速度更新，也不放宽无观测时的绘制规则，默认关闭。

三维模式采用有限历史窗口的鲁棒加权直线拟合，在线估计共同中心速度和展开相位的角速度，不是参考仓库 EKF 的逐行移植。IPPE 多解、重投影误差、姿态一致性、联合一对一关联及身份假设分别检查。存在近似等价归属时停止可信未来框，不能用空帧消除歧义。每个身份分支独立超时，过期历史不能恢复为已确认身份。同一估计器实例重获目标时 generation 递增；配置重建后 generation 从 1 重新开始，外层 epoch 递增。槽位编号必须结合 epoch 解读。

`rigid_estimator.covariance_estimation_enabled` 接入完整中心/相位协方差：同帧观测按信息矩阵融合，关联采用归一化创新软代价，历史拟合采用鲁棒广义最小二乘。原有物理距离和相位硬门限继续生效。协方差拟合若数值失败，或归一化残差劣于原鲁棒拟合，则保留原结果，避免启停段被不合适的权重拖偏。`association_nis_scale` 是软代价尺度，不是卡方硬拒绝门限。这项机制通过合成回归，但没有证明所有场景下精度更高。

二维 `tracking.shape_guard` 将中心预测有效性与完整四边形可靠性分开。以近期实测角点相对中心的变化估计形状漂移；变化过大时保留中心状态，但阻止完整未来框。它不外推角点，也不生成未观测的新轮廓。`shape_reliability.csv` 记录两种有效性及漂移值。此保护默认关闭，独立配置用于对照，因为本视频启用后预测框覆盖明显下降。

中心有效性只检查中心数值、历史、身份、协方差和时间范围，不再依赖四边形凸性。非法当前框在绘制边界拒绝，不删除其有效中心输出。`prediction_evaluation` 评分的是接受观测轨迹上的有效中心预测，不再以完整框的绘制许可筛选样本；`shape_evaluation` 仍评估框形状。两者的分母不能混用。

`rigid_state.csv` 追加 `fit_method`、`fit_selection_reason`、`scalar_fit_score` 和 `gls_fit_score`，对应最终选中的身份分支及拟合窗口。方法区分 `scalar_robust` 与 `covariance_gls`；选择原因区分关闭协方差、样本不足、GLS 残差接受/拒绝和数值失败。未计算的分数为 `nan`，不是零误差。漏检帧保留最近实际拟合的选择信息，不表示该帧发生了新拟合。

三维绿色框连接实测灯带中心线端点；橙色是未观测板的当前模型投影；红色是未来模型投影。三维框不是二维外扩包围框。等高目标的编号相对首次观测定义；高低错落目标保留三个循环身份假设，证据充分后才输出模型内确认的编号。

IPPE 初值经过已知旋转轴和灯带俯仰约束下的四参数像素重投影优化，最终门限与显示投影使用同一几何。雅可比、像素噪声、拟合残差和加速度噪声传播到中心、相位、角速度及未来四角点的不确定度；几何可投影与预测可靠分别记录。不确定度是局部线性模型结果，不是经过实物真值校准的置信概率。

连续同向创新可触发自适应短窗。完整因果历史始终保留；短窗须满足原有状态和未来角点可靠性门限才能替换完整窗，漏检时使用保留的完整窗。速度仍由观测估计，不吸附到规则速度。

`input.prefetch_frames` 为 0 时同步读取，1～8 时使用有界解码队列；队列满时等待，不丢帧。网络后端的 `detector.neural.parallel_branches` 可将传统检测与本帧网络推理重叠，但不并行提交多个 OpenVINO 帧。默认都关闭。`input_pipeline.txt` 记录容量和实际高水位；预取时 `read_ms` 是消费者等待时间，重叠阶段耗时不能直接相加为总耗时。

## 三维标定字段

`calibrated_video.template.yaml` 需要显式填写：

- `camera_matrix`：OpenCV 3×3 K，按行展开为 9 个值；`distortion`：4/5/8/12/14 项 OpenCV 畸变系数。
- `calibration_width/height`：对应标定图像分辨率；默认拒绝尺寸不一致。仅显式允许等比例缩放时同步缩放 K。
- `camera_from_target_rotation`：目标轴坐标系到相机坐标系的 3×3 正交旋转矩阵，按行展开；不是随意填单位矩阵。
- `lightbar_length_m`、`lightbar_center_distance_m`：实测中心线端点对应的灯带长度与两灯带中心距。
- `rotation_radius_m`、`armor_pitch_deg`、`slot_height_offsets_m`：旋转半径、板俯仰角和三块板各自高度偏移，单位分别为米、度、米。
- `armor_width_m/armor_height_m` 是保留的实体外形信息，不能替代上面的灯带中心线尺寸。

目标轴坐标系原点取相机中心，Z 轴为配置的旋转轴，正相位从 +X 向 +Y 旋转。第 i 块板相位为 `phase + i·2π/3`。正俯仰使灯带的向上方向向径向外侧倾斜。中心位置/速度以该轴坐标系记录，`omega` 单位 rad/s；其符号不能脱离观察方向直接称为画面 CW/CCW。

开启去畸变时，检测和估计在同一去畸变画面上进行，投影使用对应 K 和零畸变，避免重复去畸变。

## 输出与验证

二维输出包括检测来源、候选端点、关联诊断、跟踪状态、槽位、预测阻断原因、测量质量和耗时。新增 `measurement_reliability.csv` 记录两轴测量方差、ROI 来源及快速恢复状态，原有 `motion_state.csv` 保留兼容字段。

`tentative_observations.csv` 单独记录尚未确认轨迹的当帧观测显示，包含局部 ID、检测索引和当前/未来框计数。`frames.csv` 的 `drawn_current` 包含这些暂定观测，`confirmed_tracks` 仍只统计已确认轨迹；不能把两者当作同一指标。

`shape_reliability.csv` 的 `center_forecast_blended` 标记该帧是否实际使用多帧中心预测融合；它不代表关联速度已被替换，也不代表预测一定获准绘制。

三维输出单独使用 `rigid_state.csv`、`rigid_slots.csv`、`pose_measurements.csv`，记录状态、中心/速度、相位/角速度、模型有效性、身份歧义、generation/epoch、三个槽位与接受/拒绝原因，不能与二维日志的同名概念混读。

二维和三维共享同一视频、配置审计、检测、时间统计及输出完成检查主循环；通过统一工厂选择估计器。`prediction_evaluation`、`shape_evaluation`、`occlusion_replay` 目前只评分二维，收到三维配置会在读取视频、创建结果前明确拒绝，不能静默运行另一个估计器。三维由独立合成真值及实际 CLI 端到端测试验证。

`endpoint_evidence.csv` 记录左右端点支持与精化状态。三维日志追加状态可靠性、有效拟合窗、角速度标准差、未来角点标准差及几何信息比，保留原有字段顺序。

三维角点不确定度的计算不依赖绘制许可：身份未确认或提前量超时的预测仍可记录已计算的标准差，但不会因此获得绘制权限。`rigid_slots.csv` 中 `future_uncertainty_available` 表示是否得到数值结果，`forecast_block_reason` 记录首个阻断原因（身份、关联、运动确认、状态不确定、超时、投影或角点不确定度）。没有进行位姿求解的候选，其重投影和姿态误差记为 `nan`，不再用零表示。

两种模式均保存生效配置快照和变更事件。日志刷新、输入完整性检查及启用时的视频复核成功后才写 `completed`；提前退出为 `interrupted`。具体日志字段以 CSV 表头为准。
