# 统一主流程与几何估计集成验证

运行位置：Ubuntu aarch64 虚拟机 `/home/rm/robotmaster/outpost_motion`。本轮没有训练、GitHub 推送或效果视频导出。参考版本为 TongjiSuperPower/sp_vision_25 `bd9f5e798fa3c6dd3b483ae6627796afb41c608d`，未复制固定角速度或实物标定参数。

## 集成范围

- 主程序和二维预测/形状评分使用共享 Estimator 工厂；不支持三维的评分程序在产生输出前拒绝三维配置。
- 两种模式使用同一视频、检测、配置事务、审计、耗时、imshow 和输出完成流程。
- 热更新按实际消费者区分参数；保留严格字段/值检查和失败回滚。
- 可选灰度端点精化；灰度失败保留原始实测轮廓，边界支持不足拒绝；可选多帧共同截短保护。两个开关默认关闭。
- 三维固定轴/俯仰下的重投影优化、数值雅可比不确定度、有限历史速度协方差及未来角点传播。
- 自适应窗保留完整历史，选窗受相同可靠性门限约束。漏检使用完整历史拟合。

## 合成三维结果

独立渲染的56帧视频包含非零畸变、平移、旋转和14帧缺测。测试启动实际CLI并读取CSV，而不是直接调用估计器冒充端到端测试：42帧状态有效，超时重获后epoch为1；460个有效未来角点，RMS 2.7131px、最大7.58383px。评分分母仅为已发出的有效角点，同时断言最低预测数量。全部状态帧数固定56。

五个启停/反转事件各统计后续0.5秒，共75帧、900个角点；额外包含连续两帧漏检。以下误差不剔除困难过渡帧。

| 像素扰动 | 窗口 | 有效角点 | 全过渡角速度RMSE(rad/s) | 全几何角点RMSE(px) |
|---|---|---:|---:|---:|
| 0 | 固定 | 900/900 | 0.694836 | 6.87577 |
| 0 | 自适应 | 900/900 | 0.596692 | 5.48305 |
| 0.1 | 固定 | 900/900 | 0.694944 | 6.89605 |
| 0.1 | 自适应 | 900/900 | 0.595269 | 5.61816 |

无扰动下五次恢复延迟由各0.266667秒变为0.133333、0.233333、0.166667、0.133333、0.133333秒。恢复定义为连续三帧有效且角速度误差小于0.15rad/s，时间回溯至这三帧的首帧。

初次集成的激进短窗只产生792/900角点，未通过验收。修复保留完整历史和可靠性选窗后达到上表覆盖率，未放宽原不确定度阈值或覆盖率断言。

这些是已知合成标定下的测试；本视频真实K/D、轴方向及尺寸仍未知。标准差是局部线性模型输出，尚未用实物真值标定覆盖概率。
