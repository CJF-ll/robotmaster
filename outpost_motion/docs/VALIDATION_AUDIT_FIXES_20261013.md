## 已实现

1. 中心有效性不再依赖未来四边形的合法性；当前四边形非法时在绘制边界拒绝，而不是抹掉有效中心状态。完整框仍遵循形状与可见性规则。数值边界测试使用很大的测试提前量令 float 四边形退化，确认有限中心仍然有效；该提前量不是正式配置。
2. 中心评估程序只按中心有效性发出预测，不再按框是否显示筛选。形状评估保留独立职责。
3. 最终分支的拟合方法、选择原因、标量拟合分数和 GLS 分数写入 `rigid_state.csv`。自适应窗口被选中时同步复制这些字段；漏检时保留最近实际拟合信息。
4. 参数扫描对总体、逐场景、共同样本误差和覆盖设置失败断言，额外约束获取次数和身份交换。异步池及中心评分增加真实视频端到端契约。
5. 独立网络候选异步实验实现 1～4 个请求的有界池，每个请求独占输入张量，按提交顺序取回结果。调用端在提交后清空图像也不改变结果。满池、乱序帧号/时间、空输入、混合同步和待完成异步操作会被拒绝。

三维 32 组夹具共 4800 帧/策略的退化预算：

- 总体有效状态至少 4000，预测角点至少 48000，RMS < 1.85 px，最大误差 < 16 px。
- 每组有效状态至少 60/150，角点至少 720，RMS < 8 px。远距离噪声和高低错落组合在原算法中即有身份未确认区间，不能要求所有场景都达到近距离覆盖。初次采用统一 75 帧下限时，原权重策略已有 73 帧的场景失败；最终采用场景底线加更严格的总体及共同样本预算，没有改估计器去伪造确认。
- 两策略共同角点至少 48000，协方差策略 RMS 不超过原策略 1.03 倍；获取次数必须为 32，已确认高低槽位错误帧必须为 0。
